# 旧サイト・新サイト URL 対応表

ドメイン mkokusai.org は継続利用。旧 URL は `public/_redirects` により 301 リダイレクトします。

| 旧URL | 新URL | ページ |
| --- | --- | --- |
| /index.html | / | トップページ |
| /concept.html | /concept/ | 概要 |
| /eventnews.html | /eventnews/ | イベント・ニュース |
| /japanese.html | /japanese/ | にほんごきょうしつ |
| /portugues.html | /interpreter/ | 通訳について（くらしの相談） |
| /sistercity.html | /sistercity/ | 姉妹都市 |
| /speech.html | /speech/ | スピーチコンテスト |
| /wanted.html | /wanted/ | 会員・ボランティア募集 |
| /contact.html | /contact/ | お問い合わせ |
| /link.html | /link/ | リンク集 |
| /festival.html | /festival/ | 国際交流の広場 |
| /sp1/*.html | 上記各ページ | 旧スマホ版（レスポンシブ化により統合） |
| /sp1/topics.html | /news/ | 新着情報一覧 |
| （新規） | /news/ | 新着情報一覧（CMS 記事） |
| （新規） | /news/{記事ID}/ | 記事詳細 |
| /*.pdf | /files/*.pdf | 引き継ぐ PDF 資料 |

## 新サイトのサイトマップ

```
├ /japanese/      にほんごきょうしつ
├ /interpreter/   通訳について

├ /speech/        スピーチコンテスト
├ /festival/      国際交流の広場

```
