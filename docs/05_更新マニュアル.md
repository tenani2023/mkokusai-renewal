# ホームページ更新マニュアル（協会職員向け）

お知らせ・イベント記事は、パソコンのブラウザ（Chrome / Edge 推奨）から管理画面で更新できます。
専用ソフトのインストールは不要です。

## 1. 管理画面にログインする

1. ブラウザで **https://mkokusai.org/admin/** を開きます。
2. 「GitHub でログイン」を押し、協会の GitHub アカウント（ID・パスワード）でログインします。
3. 初回のみ「Authorize（許可）」ボタンを押します。

※ ログイン情報は「アカウント引き渡し資料」をご覧ください。

## 2. 記事を新しく作る（基本の流れ）

**新規作成 → 内容入力 → 公開** の3ステップです。

1. 左のメニューで「**お知らせ・イベント**」を選び、右上の「**記事を作成**」を押します。
2. 次の項目を入力します。
   | 項目 | 入力内容 |
   | --- | --- |
   | タイトル | 例：第3回MINNAのサロン 国際交流バス研修 参加者募集 |
   | 公開日 | トップページの新着情報に表示される日付 |
   | カテゴリー | お知らせ／参加者募集／開催報告／姉妹都市 から選択 |
   | サムネイル画像 | （任意）一覧に表示する画像。「画像を選ぶ」からパソコンの写真を選択 |
   | 関連ページ | （任意）例：/eventnews/ と入力すると、記事に「関連ページを見る」ボタンが付きます |
   | 下書き | オンにすると公開されません。準備中はオンにしておきます |
   | 本文 | 日時・場所・費用・申込方法など。ツールバーの「画像」ボタンで写真を挿入できます |
3. 右側の「プレビュー」で見た目を確認します。
4. 右上の「**保存**」を押します。下書きがオフなら、**数分後にホームページへ自動で反映**されます。

## 3. 公開した記事を修正する

1. 「お知らせ・イベント」の一覧から記事を選びます。
2. 内容を直して「保存」を押します。数分後に反映されます。

## 4. 記事を削除する／非公開にする

- 一時的に隠したいとき：「下書き」をオンにして保存します。
- 完全に消したいとき：記事を開き、右上の「削除」を押します。

## 5. トップページの「お知らせ（TOPICS）」を変える

1. 左のメニューで「**トップページの設定**」→「お知らせ（TOPICS）」を選びます。
2. 「表示する項目」の文章を直したり、「項目を追加」で増やしたりできます。
   強調したい部分は `<em>` と `</em>` で囲むと赤字になります。
3. 「保存」を押します。

## 6. 写真について

- 写真はアップロード時に自動で軽くなります（ビルド時に WebP 形式に変換・縮小）。
- 1枚あたり 10MB 以下を目安にしてください。
- 人物が写っている写真は、掲載の同意を得たものだけを使ってください。

## 7. 困ったとき

| 症状 | 対処 |
| --- | --- |
| 保存したのに反映されない | 5分ほど待ってからページを再読み込み（Ctrl + F5）。それでも出ない場合は GitHub の Actions 画面で「失敗」になっていないか確認 |
| ログインできない | GitHub のパスワードをリセット。二段階認証の端末を確認 |
| 画像が大きすぎると言われる | 写真を縮小（スマホなら「共有」→「サイズを小さくして送信」）してから再度アップロード |

## 8. 仕組み（参考）

記事は GitHub のリポジトリに Markdown ファイルとして保存されます。保存すると Cloudflare Pages が自動でサイトを作り直し、公開します。月額費用は発生しません。
