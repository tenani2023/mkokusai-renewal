# 技術構成の提案と運用費の検証（STEP 5 前の事前検証）

## 推奨構成

| 役割 | サービス | 月額 | 備考 |
| --- | --- | --- | --- |
| サイト生成 | Astro（静的サイト） | 0円 | ビルドは Cloudflare Pages 上で自動実行 |
| ホスティング・CDN・SSL | Cloudflare Pages | 0円 | 無料枠：ビルド 500回/月、帯域無制限。HTTPS 自動 |
| ソース管理・記事データ | GitHub（プライベートリポジトリ） | 0円 | 記事は Markdown ファイルとして保存（バックアップ兼用） |
| 管理画面（CMS） | Decap CMS または Sveltia CMS | 0円 | どちらも静的ファイルのみ。GitHub にコミットして公開 |
| CMS ログイン | GitHub OAuth（Cloudflare Workers で中継） | 0円 | Workers 無料枠 10万リクエスト/日で十分 |
| ドメイン | mkokusai.org（既存契約を継続） | 既存どおり | DNS を Cloudflare に移すか、レジストラで CNAME 設定 |

**公開後の固定費はドメイン更新料のみ**になります。

## CMS の比較（管理画面の使いやすさを優先）

| | Decap CMS | Sveltia CMS |
| --- | --- | --- |
| 日本語UI | あり | あり（翻訳が新しい） |
| 画像アップロード | 可（GitHub へコミット） | 可。アップロード時に自動で WebP 変換・縮小が可能 |
| プレビュー | あり | あり |
| 下書き／公開 | 編集ワークフローあり（下書き→レビュー→公開） | 下書き保存に対応 |
| 動作の軽さ | 記事が増えると遅くなりやすい | 高速 |
| 実績 | 長い（旧 Netlify CMS） | 新しいが Decap と設定互換 |

→ **Sveltia CMS を第一候補**とし、設定ファイルは Decap 互換で作成します（切り替え可能）。STEP 5 で実機確認のうえ決定。

## 検証が必要な制限事項

- 画像は GitHub リポジトリに保存されるため、1 ファイル 25MB 未満・リポジトリ 1GB 程度を目安に運用（CMS 側で自動縮小して回避）
- GitHub OAuth のための中継 Worker は協会名義の Cloudflare アカウントに設置
- 将来の費用発生リスク：Cloudflare Pages の無料枠超過（500ビルド/月）は通常運用では到達しない。GitHub は非営利団体向けプランも申請可能

## 必要アカウント（協会名義）

1. GitHub（info@mkokusai.org）
2. Cloudflare（同上）
3. 既存ドメイン管理会社のログイン情報
